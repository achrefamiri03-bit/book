# علماء أضاؤوا الطريق

موقع تفاعلي بسيط (صفحة رئيسية وصفحة مستقلة لكل عالم عبر #alhazen و#khwarizmi و#battani) عن ابن الهيثم والخوارزمي والبتاني، مع «مختبر اختراعات» لكل عالم.

## الهيكلة
```
scholars-site/
├── index.html        # هيكل الصفحة
├── css/fonts.css     # خط Changa المحلي
├── css/style.css     # التصميم (ألوان وأشكال مقتبسة من مشروع مسار التحرر)
├── js/app.js         # البيانات (مصفوفة D) والتبويبات والتجارب (دالة lab)
├── assets/           # صور SVG + fonts/ (حلّ محلها صورك بنفس الأسماء)
├── PROMPTS.md        # برومتات توليد الصور والتطوير
└── README.md
```

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج بناءً ولا مكتبات.

## النشر
ارفع المجلد كما هو على GitHub Pages أو Netlify أو Vercel.

## التعديل
- **إضافة عالم:** أضف كائنًا جديدًا في المصفوفة `D` داخل `js/app.js` (img, n, f, y, intro, facts, turn, a)، وأضف مفتاحه في `KEYS` وبياناته في `ST`، وحالة له في `lab(i)`، وعدّل الرقم 3 في `render` عند الحاجة.
- **تغيير الصور:** ضع صورة مربعة (WebP أو SVG) في `assets/` وغيّر اسمها في حقل `img`.
- **الألوان:** المتغيرات في أول `css/style.css`.

## الأداء
بلا مكتبات خارجية، والخط الوحيد من Google Fonts مع بدائل نظام، والرسوم SVG خفيفة، والحركة تتوقف عند تفعيل «تقليل الحركة».

## ملاحظة عن الصور
لا توجد صور حقيقية لهؤلاء العلماء؛ الأيقونات الحالية رمزية. استخدم PROMPTS.md لتوليد رسومات فنية.
